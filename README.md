# SAIES - Salesforce AI Enterprise Systems Report

A high-performance business intelligence dashboard analyzing Salesforce’s 2026 Agentic pivot, market performance, and ethical governance framework.

## Project Overview
SAIES is a professional reporting tool built to track Salesforce's transition from predictive models to autonomous agents. The dashboard focuses on the Agentforce ecosystem, utilizing real-time data to visualize the impact of AI on the enterprise landscape as of April 2026.

## Key Features
* **Live AI News Feed:** Real-time integration of Salesforce AI developments via API.
* **Agentic ROI Calculator:** Interactive widget to calculate projected efficiency gains based on 2026 automation benchmarks.
* **Zero-Copy Visualization:** Architectural breakdown of how Data Cloud processes 112+ trillion records without data movement.
* **Industry Verticals:** Specialized deep-dives into AI breakthroughs for Healthcare, Finance, and Manufacturing.
* **Einstein Trust Layer:** Analysis of Salesforce's ethical guardrails, including PII masking and toxicity detection.

## Technical Stack
* **Framework:** React (Vite)
* **Styling:** Tailwind CSS (Salesforce Blue Aesthetic)
* **Animations:** Framer Motion
* **Data Visualization:** Recharts
* **Deployment:** Vercel

## Setup and Installation for Local Environment
1. **Clone the repository:**
   `git clone https://github.com/bta5-csula/saies-salesforce-report.git`
2. **Install dependencies:**
   `npm install`
3. **Set up Environment Variables:**
   Create a `.env` file and add your News API key:
   `VITE_NEWS_API_KEY=your_key_here`
4. **Run locally:**
   `npm run dev`
